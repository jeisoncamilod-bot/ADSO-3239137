# Diseño del sistema

## Arquitectura visual

Plans Archive utiliza una interfaz React conectada
a una API REST desarrollada con Laravel.

## Interfaz

- Menu lateral de navegacion.
- Panel principal con estadisticas.
- Catalogo de planos.
- Formularios para registrar informacion.
- Mensajes de confirmacion y error.

## Diseño adaptable

La interfaz utiliza CSS y distribuciones adaptables
para diferentes tamaños de pantalla.

## Colores principales

- Azul oscuro: navegacion.
- Azul: elementos destacados.
- Blanco y gris claro: contenido y formularios.

## Objetivo

Ofrecer una interfaz clara y organizada para
administrar planos de ingenieria.
