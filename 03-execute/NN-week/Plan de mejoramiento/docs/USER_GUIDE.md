# Guia de usuario - Plans Archive

## Acceso

1. Abrir la aplicacion en el navegador.
2. Iniciar sesion con una cuenta autorizada.
3. Acceder al panel principal.

## Consultar planos

Ingresar al catalogo para visualizar los planos
registrados y sus unidades disponibles.

## Registrar un plano

1. Iniciar sesion con permisos de administrador.
2. Seleccionar Nuevo plano.
3. Completar codigo, titulo, categoria y cantidad.
4. Guardar el registro.
5. Verificar su aparicion en el catalogo.

## Prestamos y devoluciones

La API permite registrar prestamos y devoluciones.
Estas operaciones deben respetar las reglas de
disponibilidad, vencimientos y limites por ingeniero.

## Seguridad

No compartir credenciales ni publicar archivos .env.
