# Plans Archive — Documentación técnica

**Identificador:** `plans-archive`  
**Dominio:** préstamo de planos físicos de una oficina de ingeniería  
**Stack objetivo:** React, PHP/Laravel, base de datos relacional y contenedores  
**Estado:** especificación de diseño propuesta, pendiente de cotejo punto a punto con la especificación de referencia Manager Library.

## Propósito
Controlar el catálogo, las unidades, los ingenieros, los préstamos y las devoluciones de planos, con trazabilidad, disponibilidad consistente y reportes.

## Orden de lectura
1. `constitution.md`: principios y restricciones.
2. `spec.md`: alcance, actores, historias y reglas.
3. `plan.md`: fases, verificaciones y entregables.
4. `architecture.md`: componentes y flujos.
5. `data-model.md`: entidades, claves y restricciones.
6. `api-contract.md`: endpoints y errores.
7. `tasks.md`: 23 tareas propuestas con criterios de terminación.
8. `adr/`: decisiones arquitectónicas.

## Criterio de autoridad
El acta A15 determina el dominio, las reglas propias, el stack, el número de historias, reglas, requisitos no funcionales y tareas. Los detalles de las historias, endpoints y tareas de este paquete son **propuestas de adaptación** que deben cotejarse con `spec-python/` o `spec-.net/` de la referencia original antes de considerar la especificación definitiva.
